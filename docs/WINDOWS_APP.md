# Windows 桌面发行版（0.2.0 预览）

源码启动方式继续保留。桌面版使用原生 Windows 启动器与项目私有 Python，不需要安装系统 Python、Node.js、Codex，也不修改 PATH。不是把源码 BAT 改个名字。

## 普通用户使用

便携版：完整解压 `PiankeStudio-…-portable.zip` 到有写权限的本机目录，双击 `PiankeStudio.exe`。不要在 ZIP 中直接运行，也不要只复制 EXE。移动目录前停止后台并关闭启动器。

安装版：运行 `PiankeStudio-…-Setup.exe`，安装到当前用户目录，创建开始菜单与可选桌面图标。不要求管理员权限。也可在安装向导选择自己的可写目录。

首次启动会询问是否联网准备 FFmpeg 和默认字体，约下载 100–230 MB，实际依发布方构建大小变化。文件来自官方字体仓库和固定 FFmpeg 发布源；FFmpeg 校验发布方 SHA256，失败不跳过。后续已准备完整时无需再次下载。Python、核心依赖和 Node 随包携带，下载清单与哈希见 `bundle-manifest.json`。FFmpeg 不在安装包中再分发。

启动器会显示准备状态，记录日志，服务就绪后才打开浏览器。提供打开工作台、停止后台、检查／修复、查看日志。关闭启动器窗口不等于停止后台。停止按钮只管理本目录且身份核对成功的服务；有视频、分析、字幕或打包任务正在执行时拒绝停止，后台空闲时安全退出，不直接杀视频进程。

启动器默认使用本机 18765–18865 范围内的可用端口，源码版仍默认 8765。它不会结束占用端口的其他程序，不会连接另一份安装的工作清单。同目录服务已有文件锁，避免重复制作。

## 数据、更新与卸载

业务数据位于安装／便携目录的 `data/`，设置在 `configs/`，默认成片在 `outputs/`，可在网页另设保存位置。首次启动不导入原作者的商品清单、真实视频或密钥。API 默认关闭，需使用者自己配置。

升级和卸载前先停止后台并关闭启动器，否则安装程序拒绝继续。安装包仅含默认配置，不覆盖已有 `configs/storage.json`、字体设置、任务配置或队列。卸载不递归清除业务数据、模型和视频，仍应在升级／卸载前自己备份。

为保持已有源码模式兼容，本预览版数据仍与应用相邻。不要放在受保护的系统目录。移动已有目录后，若自定义成片路径不可用，需要按 README 的迁移步骤备份并调整本机设置。

## 可选功能的边界

基础发行包不含语音、翻译和视觉模型。基础剪辑、标题、原声和导出不需要模型或 API。默认使用手动时段，不自动启用智能封面。

本版私有运行时为 Python 3.14；可选模型环境原先验证基于 Python 3.12。模型安装脚本随源码保留，但未在本版私有运行时完成所有可选依赖的兼容验证，不能声称安装即支持全部 AI 功能。首次桌面预览主要验证核心流程，模型管理器后续单独完善。源码环境的现有模型配置不变。

## 开发者构建

在 Windows x64 上用已有 Python 和项目依赖运行：

```powershell
python -B scripts/build_windows.py
```

脚本使用 Windows 自带的 .NET Framework C# 编译器构建启动器，从固定官方 URL 获取校验后的 CPython 和 Node，下载锁定版本的核心 wheels，保留各组件许可证。不会复制开发者的 `tools/`、`.venv/`、原片、模型或业务目录。产物在 `dist/windows_<时间戳>/`；请使用新输出目录，不覆盖旧产物。

Inno Setup 7 编译器需开发者自行安装。指定其 `ISCC.exe` 可同时构建安装版：

```powershell
python -B scripts/build_windows.py --iscc "<Inno Setup安装目录>\ISCC.exe"
```

也可对未运行过、没有工作数据的便携目录生成安装版：

```powershell
python -B scripts/build_windows.py --installer-only "<干净便携目录>" --iscc "<编译器目录>\ISCC.exe"
```

自动验证使用隔离的解压副本。`PiankeStudio.exe --prepare` 只做组件准备，`--smoke-test` 在不打开浏览器时验证启动、复用、外部进程保护与安全停止；不要在真实业务目录使用 smoke 参数。`--can-update` 仅读取运行状态，供安装器使用。

便携包验证（会在项目 `work/` 新建隔离副本，准备媒体组件需联网）：

```powershell
python -B scripts/verify_windows_bundle.py "<便携ZIP路径>" --prepare-media
```

安装验证仅供开发者在没有同 AppId 现有安装的机器上、经用户同意后执行。它会临时创建当前用户卸载登记，在 `work/` 中安装、验证后台锁阻止升级、空闲升级保留数据、卸载后保留数据并移除登记；不接触现有源码工作台。`--media-from` 必须指向上一步已校验的隔离便携副本，只复用 FFmpeg 和默认字体，不复制业务数据。

```powershell
python -B scripts/verify_windows_installer.py "<Setup.exe路径>" --media-from "<已验证便携目录>" --allow-user-registration
```

2026-11-18 本机实测：便携版和安装版均使用私有运行时，在从 PATH 移除系统 Python／Node 后完成启动、后台复用、安全停止、8 个 HTTP 入口检查和 6 秒 1080×1440 H.264/AAC 合成素材导出、完整解码。安装验证中升级和卸载均保留了队列、加密假密钥、设置、标记文件及成片这 5 个文件的哈希，临时程序卸载登记已移除。以上不是全新 Windows 虚拟机测试、真实浏览器点击测试、全部可选 AI 模型测试或 100 条生产批次测试。验证生成的素材和日志仅保存在被 Git 忽略的 `work/`，不随发行包公开。

安装包暂未做商业代码签名，不能承诺 Windows 不显示下载／发布者安全提示。发布前核对 ZIP／EXE 哈希、源码范围、第三方许可和真实导出；不得把开发目录整文件夹压缩后发布。
