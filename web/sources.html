01 / SEARCH

选择自动检索范围

回工作台勾选商品，点击「只抓素材链接」或开始制作。按品牌型号聚合、去重与评分；网页候选未经验证，不会凭标题直接采用。已有链接和旧成片不变。

02 / CHECK & BIND

已有视频链接？直接检测。

只读取元信息，不下载、不制作、不调用大模型。其他网站也可尝试，但不是所有网站都能抓取。

保存不启动制作；下载沿用工作台队列，每条最多 15 分钟、300 MB。下载后可在商品详情本页播放、粗剪、识别字幕并生成新版。请仅处理有权使用的素材。

SOURCE COVERAGE

接收这些站点的链接

这是链接适配入口，不是每站下载成功的保证。自动发现以 YouTube、B站和公开网页检索为主，其他站点粘贴链接读取。

遇到限制，清楚地停下来。

需要登录、验证码、付费权限、DRM 或平台限制时，会说明原因。不会自动提取浏览器 Cookie、破解 DRM、去除水印或假报下载成功。

优先使用品牌官网或授权素材。国内外网站的可用性随网络和平台变化，检测成功也不等于拥有使用许可。

不开启 SnapAny 时只使用原本地下载器；开启后，下载任务的视频链接会发给 SnapAny，原片仍保存到本机项目目录。

03 / SNAPANY API

把多平台解析，接进你的下载流程。

不是内嵌网页，也不需要离开工作台下载。保存密钥 → 免费检查余额 → 选择下载模式。解析能力取决于官方支持与素材权限，不保证每条都成功。

① 创建你自己的 API 密钥

在官方平台注册或登录，创建 API Key。不要发到聊天中；这里不使用 DeepSeek 密钥。

打开 SnapAny 官方密钥页面 ↗

Windows DPAPI 加密保存在本机项目目录，仅当前 Windows 账号可解密；密钥不回显、不写商品清单、不进入 Git。更换密钥或区域后，需重新检查连接。

② 选择怎样用于批量任务

先试一条，清楚地看结果。

使用上方“已有视频链接”输入框。此按钮只解析、不下载；之后开启“优先使用 SnapAny”，点击“保存并仅下载原片”，即可沿用现有商品队列。也可选择“本地失败后使用”。

同一链接在 10 分钟内可复用内存解析结果，避免重复扣费；重启或更换密钥、接口区域后失效，切换下载模式不清除缓存。开启自动模式不会批量重做历史成片。
