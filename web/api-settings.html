01

登录开放平台，创建密钥

这里需要的是开放平台 API 密钥，不是聊天网站密码。

  1. 点击下方按钮，在 DeepSeek 官方开放平台登录或注册。
  2. 进入「API keys / API 密钥」，点击创建，名称可填「片刻工作台」。
  3. 复制生成的完整密钥。不要发到聊天里，直接粘贴到下面的本机入口。
打开 DeepSeek 官方密钥页面 ↗

登录、验证码、支付和协议确认由你自己操作。先检查可用余额；不用为了连接检查立即充值，是否需要充值以官方控制台为准。

02

只在这台电脑上保存密钥

保存不会向 DeepSeek 发请求，也不会生成视频。

官方地址 api.deepseek.com视觉模型 deepseek-flash

Windows DPAPI 加密，文件保存在本机项目目录。不会回显密钥，不写入商品清单或日志；拷到别的电脑／Windows 账号后需要重新填写。

03

先试一条，再决定是否自动使用

连接通过不等于实际看图效果已验证。

  1. 返回工作台，打开一个已有素材的商品。
  2. 先点「只分析选片」，得到本地分镜。
  3. 点新增的「DeepSeek 复核这条」，确认上传和计费后试用。
  4. 核对建议，再点「采用云端建议」，用原有「保存时段并生成」输出新版。
返回工作台选一条试用 →
试用满意后：开启新任务自动辅助

这是本机次数保护，不是人民币预算；失败请求也占次数，可能已被服务商计费。每条最多请求一次、不自动重试、不切换平台。原手动时段及旧排队任务不自动启用。
