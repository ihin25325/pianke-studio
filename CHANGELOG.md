# Changelog

## 0.1.0 — first source release candidate

- Windows local product-video workbench: CSV/XLSX queue, source discovery,
  manual review, batch jobs, redo and versioned outputs.
- Public multi-site URL extraction/download attempts with local yt-dlp and an
  optional opt-in SnapAny fallback; neither universal download success nor
  commercial rights are implied.
- FFmpeg 1080×1440 product layout, editable text, clip ranges, subtitles,
  local wordmarks, reusable brand assets and a one-second ending fade.
- Optional offline speech/translation/visual analysis; optional DeepSeek review.
- MIT source license, local installer, dependency checks, synthetic offline
  demo, clean-release checks, test workflow and filtered source ZIP packaging.
- No original business table, credentials, downloaded videos, models or binary
  toolchains included. Existing local settings and originals remain untouched.
- Portable UI/help text without a fixed project drive; reviewed base/premium
  font guides included in source releases. Generated font specimen notes stay
  in local outputs and do not overwrite the published guides.

Known limits: Windows only; third-party sites and downloads may fail; optional
model/API features need separate setup; no hosted multi-user service, arbitrary
watermark removal, guarantee of correct SKU matching or 100-item live end-to-end
certification.
