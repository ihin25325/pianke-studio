# 商品视频字体包

本说明介绍基础字体及本地预览方式，不表示字体已在当前电脑安装。所有路径均相对于项目根目录；源码只保留说明和许可，不附带字体二进制文件或本机下载清单。

默认安装器下载 Oswald Regular / SemiBold 和思源黑体 Regular / Bold，保存在 `assets/fonts/`，不安装到 Windows 系统目录。默认搭配为 Oswald 英文＋思源黑体中文；安装字体不会覆盖已保存的排版设置。

需要下列全部基础字体和高级字体包时，在项目目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/setup.ps1 -AllFonts
```

安装完整字体包后，可生成本机字体对比图：

```powershell
.\.venv\Scripts\python.exe -B scripts/font_specimen.py
```

结果写入 `outputs/字体对比.png` 和 `outputs/字体对比说明.md`，不会改写本说明或工作台的字体设置。对比脚本需要完整基础字体及 `assets/fonts/font_manifest.json`，只安装默认四个字体文件时不适用。

| 字体 | 内部字体名称 | 建议用途 |
| --- | --- | --- |
| 思源黑体 | Source Han Sans CN | 清晰、利落；推荐用于商品标题和类别。 |
| 思源宋体 | Source Han Serif CN | 偏经典、精致，适合乐器或有质感的商品标题。 |
| 霞鹜文楷 | LXGW WenKai | 柔和、有书写感，适合较轻松的商品风格。 |
| Montserrat | Montserrat | 几何感鲜明，推荐用于英文品牌与型号；不含中文字形。 |
| Oswald | Oswald | 窄长、醒目，适合英文大标题；不含中文字形。 |

建议搭配：Oswald SemiBold 显示英文品牌/型号，思源黑体显示中文商品类别。可在工作台「文字与字体」中自行调整。

Montserrat 与 Oswald 是可变字体，可选择不同粗细；对比图分别使用 700 和 600 字重。两者不含中文字形。

各字体采用 SIL Open Font License 1.1，可在许可范围内用于商业视频。每个家族目录保留 OFL 文件；再分发字体时须保留相应授权和版权信息。完整基础包的来源链接、下载时间、文件大小与 SHA-256 由下载器记录在 `assets/fonts/font_manifest.json`，属于本机生成文件，不纳入源码。

基础包下载原始字体文件，不修改字形。视频使用的字重会暂存到 `assets/fonts/render/`，供本机渲染器加载，无需安装为系统字体。更多可选风格见 [高级字体包说明](高级字体包说明.md)。
