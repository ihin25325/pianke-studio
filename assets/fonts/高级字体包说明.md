# 高级字体包

这是可选的 8 个字体家族，不包含在默认四个字体文件中。原有字体、已保存字体配置和默认搭配保持不变；文件安装到项目的 `assets/fonts/`，不安装到 Windows 系统目录。源码只附带本说明与许可，字体需另行下载。

## 安装

在项目根目录运行以下命令，安装完整基础包与高级包；首次下载需要联网：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/setup.ps1 -AllFonts
```

安装后可在工作台「文字与字体」中选择预设。正常预览和导出使用已生成的静态字体，不需要再次下载，也不需要 fontTools。英文家族需与中文字体搭配。

| 内部家族名称 | 风格与适用内容 |
| --- | --- |
| Inter | 清晰现代，英文品牌与型号，提供 400/700 静态字重。 |
| Manrope | 高级几何感，通用英文商品标题，提供 400/700 静态字重。 |
| Space Grotesk | 科技、工业感，英文器材和数字型号，提供 400/700 静态字重。 |
| Bebas Neue | 海报窄体，适合英文大写短标题，仅 Regular。 |
| Outfit | 圆润、现代，英文生活方式商品，提供 400/700 静态字重。 |
| ZCOOL QingKe HuangYou | 站酷庆科黄油体，圆角黑体感，适合中文短标题和封面，仅 Regular。 |
| ZCOOL XiaoWei | 站酷小薇体，宋黑结合，适合中文商品类别或精致标题，仅 Regular。 |
| Ma Shan Zheng | 马善政楷书，毛笔风格，适合少量人文标题，不建议用于长字幕，仅 Regular。 |

英文家族不包含完整中文，请在混合中英文时回退到思源黑体，避免方框或错误排版。中文风格字体也并非覆盖全部罕见汉字；通用长文、语音字幕仍推荐思源黑体。单字重字体建议关闭加粗，以保留作者原始笔画。

## 许可与来源

来源为 Google Fonts 官方仓库的固定提交 `cc39c4c2c304bc368c9b7c311ea2bcc6013299fe`。每个家族目录保留完整 OFL.txt，许可为 SIL Open Font License 1.1。可在许可范围内用于商业成片；再次分发字体必须连同版权和许可文本保留，不得把字体本身单独出售。商标/商品素材的授权与字体授权是两回事。

安装后生成的 `assets/fonts/premium_font_manifest.json` 记录下载网址、来源版本、原始文件与成品的 SHA-256、字体内部家族名、字重、字符数量和转换工具版本。变量字体只做静态实例化，没有修改字形设计；原始变量文件也保留在相应目录。下载清单、字体二进制和渲染缓存不纳入源码发布。

## 重建与集成

通常使用上面的安装入口即可。手动重建时，在项目根目录执行；以下命令只影响项目私有环境和工具目录：

```powershell
.\.venv\Scripts\python.exe -m pip install --target tools/fonttools-runtime fonttools==4.60.1
.\.venv\Scripts\python.exe -B scripts/download_premium_fonts.py
```

渲染器从 `scripts/premium_fonts.py` 的 `PRIVATE_FONT_FILES` 合并私有字体映射；每个家族对应 Regular/Bold 两个路径。单字重字体的两条路径相同。沿用原有 `stage_private_fonts` 将实际用到的字重复制进 `assets/fonts/render`，供 libass 加载。字体真实家族名称由 manifest 核对，不要把展示用中文标签写进 ASS 字体名。

网页样式 `web/font-library.css` 使用本机服务的 `/font-assets/<家族目录>/<文件名>.ttf`，不是操作系统的绝对文件路径。后端仅允许清单列出的静态 TTF，不接受任意路径；浏览器按实际使用懒加载。`FONT_PRESETS` 提供可自愿选择的搭配，不自动覆盖用户当前设置。基础安装与对比图生成方式见 [基础字体说明](使用说明.md)。
